# Video converter
<img width="299" height="399" alt="image" src="https://github.com/user-attachments/assets/1c800552-f1ea-47f7-a936-efcd08eeed95" /> \
A tool for changing quality and resolution of videos and converting them to mp4\
It uses subprocess to communicate with ffmpeg so **ffmpeg must be installed**\
Supports converting multiple files at once, it uses hardware-accelerated encoder that uses the GPU if available

To use the app, download the latest release and install it or run the source code
